This assignment develops an AI-based intrusion detection system using the CIC-IDS2017 web attacks dataset, focusing on detecting benign and malicious network traffic. It covers end-to-end processing including data cleaning, class balancing, exploratory analysis, feature engineering, and feature selection to improve model reliability. A Logistic Regression model is trained for both binary and multi-class classification, achieving high overall accuracy while highlighting challenges in detecting low-frequency attacks such as brute force, XSS, and SQL injection.
